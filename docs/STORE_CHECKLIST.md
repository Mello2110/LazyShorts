### Icon Requirements
The current icons (777KB each) are way too large and include text + background.

**What you need:**
- Just the red "S" logo icon, no text, no dark background
- Transparent or white background
- Properly sized: 16x16, 32x32, 48x48, 128x128 PNG

🚀 LazyShorts - Auto-Skip YouTube Shorts

Tired of manually swiping to the next Short? LazyShorts automatically advances to the next video when the current one finishes playing - completely hands-free!

✨ FEATURES:
• Automatic Skipping - Seamlessly advance to the next Short after it ends
• Adjustable Delay - Set 0-5 seconds delay before skipping

• Dark Mode - Supports light, dark, and auto themes
• Privacy First - No data collection, works 100% offline
• Lightweight - Minimal CPU and memory usage

⚙️ HOW IT WORKS:
1. Install the extension
2. Go to YouTube Shorts
3. Watch videos - LazyShorts handles the rest!
4. Click the extension icon to enable/disable or adjust settings

🔒 PRIVACY:
LazyShorts does NOT collect any personal data. All settings are stored locally on your device. No network requests, no tracking, no analytics.

📱 PERFECT FOR:
• Binge-watching YouTube Shorts
